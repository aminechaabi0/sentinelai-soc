Quick setup

Keep secrets server-side. Do not expose API keys in frontend code or commit your .env file.

  1. Copy .env.example to .env and set strong random keys.
  2. Start the API and open the dashboard in your browser.
  3. Use the API key configured in your browser's session prompt.
  4. Configure Wazuh or Suricata to forward events to the documented endpoints.
  5. Test with a synthetic event first; verify mappings and timestamps before production use.
